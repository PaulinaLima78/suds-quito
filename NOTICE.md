# Componentes y datos de terceros

SUDS Quito es obra original de Paulina Lima. Para funcionar utiliza las
siguientes bibliotecas de código abierto, que **no** forman parte de la obra
y conservan sus licencias (todas permisivas):

| Biblioteca | Uso | Licencia |
|---|---|---|
| React / React DOM | Interfaz de usuario | MIT |
| Leaflet | Mapa interactivo | BSD-2-Clause |
| lucide-react | Íconos | ISC |
| Tailwind CSS | Estilos | MIT |
| Vite, @vitejs/plugin-react | Compilación | MIT |
| Vitest | Pruebas automáticas | MIT |

Servicios y datos externos:

- **Datos de lluvia:** FONAG — Fondo para la Protección del Agua (Quito), 12
  estaciones, serie horaria 2020-2026, acceso libre. Los valores de diseño
  (percentiles, ajuste de Gumbel, climatología) fueron calculados por la
  autora a partir de esos registros.
- **Cartografía base:** © colaboradores de OpenStreetMap (ODbL).
- **Tipografías:** Fraunces e Inter, Google Fonts (SIL Open Font License).
- **Precios unitarios:** Lista de Rubros del Municipio de Rumiñahui (junio 2026).
